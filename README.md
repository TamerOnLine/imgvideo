# imgvideo

واجهة عربية محلية لإنتاج نسخ فيديو بلا صوت، مع حفظ الملفات الأصلية ونسخ الفيديو دون إعادة ترميز.

## التشغيل داخل Ubuntu / WSL

المتطلبات: Python 3 وFFmpeg وFFprobe. لا توجد حزم Python خارجية.

```bash
sudo apt install python3 ffmpeg
python3 app.py --port 42120
```

افتح http://localhost:42120/ . الخادم محلي فقط؛ لا تعرضه للإنترنت.

## الاستخدام

1. اختر مجلدًا من نافذة التصفح داخل التطبيق، أو أدخل مسار Windows أو WSL.
2. اعرض الفيديوهات، وألغ تحديد الملفات غير المطلوبة.
3. اختر مجلد إخراج منفصلًا؛ يمكن استخدام الاقتراح وتفعيل إنشاء المجلد.
4. ابدأ المعالجة وتابع نتيجة كل ملف.

أقراص Windows يجب أن تكون متاحة داخل WSL تحت /mnt. التطبيق لا يركب الأقراص أو يضبط Google Drive تلقائيًا. اختيار المجلد داخل التطبيق؛ أداة Windows الأصلية الموجودة في folder_picker.py تجريبية وغير مستخدمة في الواجهة الحالية.

## النتائج والتحقق

الناتج MKV، مع إزالة الصوت والترجمة والبيانات الإضافية. يفحص التطبيق غياب الصوت، وثبات ترميز وبصمة حزم الفيديو، وإمكان فك القراءة، وبقاء الأصل دون تغيير. عدم توافق النسخ مع الحاوية يؤدي لفشل واضح دون إعادة ترميز تلقائية.

لا يستبدل التطبيق نتائج موجودة. الاستئناف يعتمد على بصمات المصدر والنتيجة وسجل JSON. تبقى الملفات الجزئية الفاشلة للتشخيص. يحتاج نظام ملفات الإخراج إلى دعم hard links.

## الاختبار

```bash
python3 verify.py
```

ينشئ الاختبار عينات اصطناعية مؤقتة ويكتب دليلًا محليًا في state/verification.json. لا يستخدم فيديوهات شخصية.

## الخصوصية والحدود

لا حسابات أو رفع سحابي. إعدادات الأدوات وسجلات التشغيل محلية في state/ ومستبعدة من Git. لا تحتوي النسخة العامة على سجل الإدارة أو تعليمات المالك أو عيناته. أوقف التطبيق بعد انتهاء الدفعة. لا يُستعاد عرض التقدم بعد إعادة تشغيل الخادم؛ يمكن إعادة تقديم الملفات للتحقق من النتائج المكتملة.
