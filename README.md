# imgvideo — فيديو بلا صوت
أداة محلية لإزالة جميع مسارات الصوت من دفعات فيديو متتابعة دون تعديل الأصول. واجهة عربية فاتحة/داكنة؛ الناتج MKV مع نسخ بيانات الصورة دون إعادة ترميز. إزالة الترجمة والبيانات الإضافية مقصودة.

## التشغيل على جهاز آخر
المختبر: Ubuntu 22.04 داخل WSL2، Python 3.10، FFmpeg/FFprobe 4.4. لا حزم pip خارجية. يحتاج Linux إلى fcntl، لذلك Windows المباشر غير مدعوم؛ شغّلها داخل WSL. لم تختبر توزيعات Linux الأخرى تشغيليًا.
افك الحزمة في مجلد مستقل داخل Linux/WSL، وثبت Python3 وFFmpeg من مستودع نظامك عند نقصهما، ثم من مجلد imgvideo نفذ:
```sh
bash run.sh
```
افتح http://localhost:42120/؛ الخادم محلي فقط. أوقفه بـCtrl+C بعد انتهاء الدفعة. لا خدمة تلقائية أو حسابات أو اتصال سحابي.

## الاستخدام
1. اختر المجلد داخل التطبيق أو الصق مسار Windows/WSL؛ أقراص Windows يجب أن تكون متاحة تحت /mnt. لا تركيب أقراص أو إعداد Google Drive تلقائيًا.
2. اعرض الفيديوهات، وألغ تحديد غير المطلوب. اختر مجلد إخراج منفصلًا أو الاقتراح، وفعّل إنشاءه إذا لزم.
3. زر «حفظ مجلدات العمل» يحفظ الاختيار محليًا فقط دون بدء معالجة؛ تُستعاد الاختيارات عند فتح الصفحة.
4. ابدأ الدفعة وتابع عدد النجاح والفشل. لكل نتيجة متحققة رابط تنزيل مباشر.
5. إذا انقطع الخادم تظهر حالة انقطاع عند التشغيل التالي. «استئناف آخر دفعة محفوظة» يعيد فحص بصمات المكتمل ويتابعه دون استبداله. الاستئناف صريح وليس تلقائيًا؛ المسار المحفوظ يجب أن يبقى متاحًا.

## ضمانات وحدود
يُفحص غياب الصوت وثبات ترميز وبصمة حزم الفيديو وإمكان فك القراءة وبقاء الأصل دون تغيير. عدم توافق الحاوية يفشل بوضوح دون إعادة ترميز تلقائية. لا استبدال لنتيجة قائمة دون سجل اكتمال مطابق. نشر الملف ذري باستخدام hard link؛ يلزم نظام ملفات يدعمه. تبقى الملفات الجزئية الفاشلة للتشخيص ولا تعتبر نجاحًا. لا حذف تلقائي.
حالة الواجهة بعد انقطاعها لا تعني نجاح الملف الجاري؛ يعاد التحقق عند الاستئناف. ملفات العمل والإعدادات ومسارات المستخدم محلية في state ولا تدخل حزمة المصدر. أداة Windows الأصلية folder_picker.py تجريبية غير مستعملة في الواجهة؛ المنتقي الحالي داخل التطبيق.

## الاختبار وحزمة النقل
```sh
python3 verify.py
python3 verify_workflow.py
python3 package.py /path/to/new-imgvideo.zip
```
الاختبارات اصطناعية فقط. الحزمة قائمة ملفات مصدر صريحة، وتستبعد state والوسائط وسجل الإدارة وتعليمات المالك والاعتمادات. لا تستبدل حزمة موجودة. فك الضغط في مجلد جديد؛ لا تستبدل ملفات مشروع آخر. لا تتضمن الحزمة Python أوFFmpeg، ولا تثبتهما تلقائيًا.
